# 💡 ESP32 LED Control via Web Interface

## 📌 Description
This project demonstrates how to control an LED using an ESP32 microcontroller through a web interface.
The ESP32 acts as a web server, allowing users to turn the LED ON or OFF using a smartphone connected to the same Wi-Fi network.

---

## 🎯 Objective
- Create a simple IoT system
- Control hardware remotely using a web page
- Understand ESP32 web server functionality

---

## 🛠️ Technologies Used
- ESP32
- Arduino IDE
- Wi-Fi Communication
- HTML (Web Interface)

---

## ⚙️ How It Works
1. ESP32 connects to Wi-Fi
2. It creates a local web server
3. User opens the web page from their phone
4. Clicking a button sends an HTTP request
5. ESP32 turns the LED ON or OFF

---

## 🔌 Components
- ESP32 board
- LED
- Resistor
- Breadboard
- Jumper wires
